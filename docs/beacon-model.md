# Beacon Model

A Point X beacon is a spatial target that can be saved, followed, reached or combined with other beacons.

A beacon may include:

~~~text
id
name
latitude
longitude
arrival radius
visibility
type
metadata
~~~

## Visibility

Possible scopes include:

- Private
- Shared
- Public
- Official / Verified
- Temporary

## Behaviors

A beacon may act as:

- Navigation target
- Checkpoint
- Information point
- Achievement
- Puzzle or clue
- Route step
- Safety point
- Meeting point

Beacon behavior is intentionally separate from navigation itself.
