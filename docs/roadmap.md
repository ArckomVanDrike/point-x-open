# Roadmap

Point X is in early development.

## Current foundation

- Drop X
- Follow X
- Arrival radius
- Positioning confidence
- Compass-based relative direction
- Trace X
- Stabilized breadcrumb recording
- Cross-platform sensor contract
- Cross-platform target snapshot

## Next areas

- Trace activity records
- Moving time and pause detection
- Altitude and elevation metrics
- Beacon sequences
- Native application
- Phone widgets
- Watch and wearable clients
- Smart glasses / HUD experiments
- Beacon collections and map-based organization
- Shared and public beacons
- Beacon packs
- Checkpoints and achievements
- Treasure-hunt / puzzle behaviors

## Later research

- Live beacons
- Safety-oriented location sharing
- Public / official beacon infrastructure
- Third-party SDK and interoperability
